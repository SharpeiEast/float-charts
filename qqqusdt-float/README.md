# QQQUSDT Float

一个可以挂在桌面上的小窗口,实时显示蜡烛图。每个窗口左上角有一个**下拉菜单**选品种,目前三项:

- **QQQ**:币安 QQQUSDT 永续合约。顶行是两个数字:前一个是 Yahoo 的 QQQ 最新价(盘前、盘中、盘后都取最新),后一个是币安 QQQUSDT 最新价,后面的小圆点是币安数据流的连接状态;QQQ 价格后面还有一个小圆点,是 Yahoo 推送的状态
- **ETH Perps**:币安 `ETHUSDT` 永续合约
- **BTC Perps**:币安 `BTCUSDT` 永续合约

支持 3 分钟 / 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 4 小时 / 日(1d)/ 周(1w)/ 月(1M)周期,可开关布林线(20 根均线 ± 2σ)。所有数据都由你自己的电脑直接连币安和 Yahoo,不经过任何中转服务器。

## 两种用法

| 版本 | 位置 | 怎么用 |
|---|---|---|
| 网页版 | `web/qqqusdt_float.html` | 把这一个文件拷到电脑,用 Chrome / Edge(116 以上)打开,点右上角「浮窗」得到置顶小窗口 |
| 程序版 | Releases 里的 `.exe` / `.zip` / `.deb` | Windows 双击 exe;Mac 解压后打开 `.app`;Ubuntu 用 `sudo apt install ./xxx.deb`。Windows / Mac 窗口自带置顶,不需要浏览器 |

程序版内部就是把同一个网页放进系统自带的网页组件(Windows 的 WebView2、Mac 的 WebKit),所以两个版本画面和功能一致。

### Ubuntu / Debian 桌面版

Releases 里的 `qqqusdt-float_<版本>_all.deb`。装法:

```
sudo apt install ./qqqusdt-float_<版本>_all.deb
qqqusdt-float
```

也可以在应用菜单里找「QQQUSDT Float」。它用系统自带的 GTK 和 WebKit(`python3-gi`、`gir1.2-webkit2-4.1`,安装时会自动带上),所以窗口、画面和功能和其他系统一致,SIMU 面板展开时窗口会向右变宽。已在 Ubuntu 26.04(Python 3.14,Wayland 桌面)上实测,编译机用 22.04 构建并自动测试。和 Windows / Mac 版的区别:Ubuntu 版**不置顶**(Wayland 不允许程序自己置顶,要置顶用窗口标题栏菜单里的「始终在最上面」)。程序默认走 XWayland(`GDK_BACKEND=x11`),这样窗口才能自己变宽;要改成原生 Wayland 可以先设 `GDK_BACKEND=wayland`,但那样 SIMU 面板展开时窗口可能不会自己变宽(没有实测)。卸载:`sudo apt remove qqqusdt-float`。

### Windows 首次运行
没有代码签名,Windows SmartScreen 会提示"未识别的应用":点「更多信息」→「仍要运行」。需要系统自带的 WebView2 运行库(Windows 10/11 一般已经有,没有的话装 Edge 即可)。

### Mac 首次运行
程序没有苹果的开发者签名和公证,macOS 会给下载来的文件加上隔离标记并拒绝运行(macOS 15 起「右键 → 打开」也绕不过去)。每个新下载的副本只需要在终端做一次,把 `.app` 放在「下载」或「桌面」等位置后,在它所在的目录执行:

```
xattr -cr QQQUSDT-Float.app
codesign --force --deep --sign - QQQUSDT-Float.app
```

之后直接双击即可。如果这两条命令自己提示 `Operation not permitted`,把 `.app` 挪到 `~/Applications` 再做。Apple 芯片用 `macos-arm64` 那个包,Intel 芯片用 `macos-intel` 那个。解压请用 Mac 自带的方式(双击 zip),不要用第三方解压工具,否则 `.app` 里的符号链接可能丢失。

## 多窗口(程序版)

- 右上角 **＋** 再开一个窗口,最多同时 3 个;新窗口出现在现有窗口的正下方,第一次依次是 QQQ、ETH、BTC(已经开着的品种会跳过)
- 每个窗口可以单独关闭,关掉中间的窗口后再点 ＋,新窗口会补在空出来的位置
- 每个窗口的品种、周期各自独立,可随时用下拉菜单换品种;下次启动会按上次关闭时的窗口数、品种、周期恢复
- 满 3 个窗口时点 ＋ 会在右上角提示"最多同时打开 3 个窗口"
- 网页版(浏览器)点 ＋ 会弹出另一个小窗口,显示菜单里的下一个品种

## 操作

- 顶部 `3m / 5m / 15m / 30m / 1h / 4h / 1d / 1w / 1M` 切换周期(默认打开是 1h);**BL** 按钮开关布林线(按下变蓝色 = 显示布林线,再按一下弹起 = 隐藏)
- 滚轮缩放,拖动平移(向左拖可以把最新一根蜡烛拖离右边缘,右侧留出空白),双击复位
- 左上角默认显示最新一根蜡烛的开高低收(带「● 当前」),鼠标放在别的蜡烛上显示那一根
- QQQ 价格后面的小圆点(Yahoo):绿色 = 90 秒内收到过报价,推送正常;黄色 = 已连接但暂时没有新报价(休市或无成交时正常);红色 = 连接断开,正在重连;灰色 = 正在连接。
- 第二个数字后面的小圆点(币安):绿色 = 币安 WebSocket 实时推送正常;黄色 = 改用每 3 秒轮询;灰色 = 正在连接;红色 = 出错。鼠标放上去有文字说明。它只反映币安的连接,和 Yahoo 的 QQQ 价格无关
- 鼠标放在第一个数字(QQQ)上,提示当前时段(盘前 / 盘中 / 盘后)和最后更新时间;休市没人成交时数字会变淡
- 网址后加 `?market=spot` 改看现货 QQQBUSDT;程序版命令行加 `--spot` 同理(QQQ 换成现货 QQQBUSDT,ETH、BTC 换成对应的币安现货 ETHUSDT、BTCUSDT)
- 网址后加 `?inst=eth`(或 `btc`、`qqq`)直接打开指定品种
- 程序版会记住窗口位置和大小,存放在:Windows `%APPDATA%\qqqusdt-float\windows.json`,Mac `~/Library/Application Support/qqqusdt-float/windows.json`;同目录的 `app.log` 记录开关窗口和错误(旧版的 `window.json` 不再使用,可以删除)

## 模拟合约交易(练习用)

顶栏的 **6格** 按钮把窗口变成六个周期同时显示(3 分钟、5 分钟、15 分钟、30 分钟、1 小时、4 小时,3×2 排布,窗口较窄/竖屏时自动变成 2×3),程序版窗口会自动放大,点「← 单图」回到原来的大小。六格里可以切换品种和开关布林线,每格各自缩放、拖动;六格里没有模拟交易面板。

顶栏的 **SIMU** 按钮点一下,窗口向右侧展开一个模拟交易面板,不会盖住 K 线图,图表大小不变(再点一下或点 ✕ 收回;程序版窗口会自动变宽 250 像素再变回来,靠近屏幕右边缘时窗口会自动向左挪一点;网页版没法改变浏览器窗口大小,面板会占用页面右侧 250 像素,图表相应变窄)。没有本金、不记录历史,每次只做一单:

- **品种**:QQQ(最大杠杆 25x)、ETH Perps、BTC Perps(最大杠杆 150x),价格用币安对应永续合约的最新价,和图表看哪个品种无关
- **杠杆**:滑块或直接输入,超过品种上限会自动改回上限
- **市价 / 限价**:默认市价,点「开仓」按现价成交。选「限价」可以提前挂单:填一个**限价**(到这个价位才开仓)和**有效期**(分钟,不填默认 30,可填 1 到 1440),点「挂单」。挂单后面板显示倒计时、现价和离限价的距离,顶栏 SIMU 按钮也显示剩余时间,可随时「撤单」。**挂单后还没成交时,限价、杠杆、止盈价、止损价、倒计时都可以直接在面板里修改**(改完按回车或点别处生效;改倒计时是从现在起按新的分钟数重新计时;新的限价不能和止盈止损冲突,不合理的修改会被拒绝并恢复原值;把限价改成现价会立刻成交);价格到了限价就自动按这个价开仓(转为持仓,止盈止损照常生效),倒计时走完还没到价就自动撤单,不再开仓。限价低于现价做多(或高于现价做空)是回落/反弹到价成交,按限价成交,手续费按挂单 0.02%;反方向(突破型)是价格冲过这个价位的那一笔成交,按那一笔价格成交,手续费按吃单 0.05%。挂单期间图表上画出挂单价和止盈止损线,止盈止损相对限价检查
- **Buy 做多 / Put 做空**
- **止盈价 / 止损价**:可选,填价格点位,旁边会显示到那个价位时的本金收益率;持仓中也可以修改。价格到达就按当时价格自动平仓
- 持仓中面板显示本金收益率(大字)、开仓价、现价、爆仓价和持仓时长;面板收起时 SIMU 按钮后面会显示当前收益率(绿涨红跌)。如果图表正在看这个品种,图上会画出入场、止盈、止损、爆仓四条线
- **平仓**(手动、止盈、止损、爆仓)之后显示**交易总结**:方向、杠杆、开平仓价、价格变动、本金收益率、手续费、持仓时长、期间最高/最低收益。点「确定」回到开仓界面,总结不会保存

计算方式:本金收益率 = 方向 × 杠杆 × (现价 / 开仓价 − 1),可选再扣开平两次手续费(市价和止盈止损按吃单 0.05% × 名义价值,限价挂单成交按 0.02%,杠杆越高占本金的比例越大,150 倍时吃单开平各约 7.5%)。爆仓条件是保证金加浮动盈亏减开仓手续费不足以覆盖维持保证金(名义价值 × 维持保证金率),BTC / ETH 取 0.4%(币安第一档),QQQ 的 2% 是估计值,爆仓时按本金全部亏光(−100%)计。没有计入资金费率、滑点和盘口深度,价格取币安 1 秒一次的最新价推送,所以高杠杆的止盈止损、爆仓可能比真实成交稍微晚或早一点。这只是练习工具,不是真实交易。

### 服务器模式(电脑关机也照常运行)

默认是本地模式:挂单和持仓只在软件里算,关掉软件就停。想让它在一台一直开着的机器上跑,用 `server/simu_server.py`:

- 服务器一直盯着币安合约价格(逐笔成交,断线后用 K 线补查,不会漏掉插针),替你完成限价成交、倒计时撤单、止盈、止损、爆仓,状态存在 `state.json`,重启不丢。
- 限价挂单成交、止盈、止损、爆仓时发 Bark(`~/bin/bark-notify`)。你自己手动点的市价开仓、手动平仓、撤单、挂单超时都不发。
- 每次平仓后的交易总结里可以选「记录到 us01a, 再来一单」(可附一句复盘备注)或「不记录, 再来一单」。选记录的交易追加到服务器上的 `trades.jsonl`(与 `state.json` 同目录,每行一笔,含品种、方向、杠杆、开平仓价、止盈止损价、收益率、手续费、持仓时长、期间最高/最低收益、平仓原因、备注),所有装了软件的电脑共用这一份。`GET /api/trades?n=200` 可读取。本地模式没有这个选项。
- 软件和网页版只负责下单、改单和查看。面板右上角 ⚙ 里服务器地址已经默认填好(`http://100.78.175.68:8765`),口令也不用填(服务器只监听 Tailscale 和本机,Tailscale 里的设备直接放行;别的来路才需要口令,在服务器的 `~/.config/simu/token`)。要换地址就改完点「保存并连接」,留空 = 回到本地模式。填好后面板上方会显示「服务器: 已连接」。
- 服务器同时提供网页版:浏览器直接打开 `http://<服务器地址>:8765/`,手机也能用。
- 同一时间只有一个持仓或一个挂单(和本地模式一样)。离线期间平掉的单,下次打开会自动弹出交易总结。
- 部署:`server/simu_server.py` 只用 Python 标准库。示例 systemd 用户服务见 `server/simu.service`。建议只监听 Tailscale 地址和 127.0.0.1(`--host` 可重复),口令是第二道门。
- 价格口径:币安合约逐笔成交价。止盈止损成交在触发的那一笔价格(和本地模式一致),不是止盈止损价本身。

## 数据从哪里来

| 数据 | 地址 |
|---|---|
| 历史 K 线 | `https://fapi.binance.com/fapi/v1/klines`(币安 USDS-M 永续) |
| 实时 K 线和最新价 | `wss://fstream.binance.com/market/stream`(注意是 `/market/stream`,旧的 `/ws`、`/stream` 能连上但收不到数据) |
| QQQ 价格 | `wss://streamer.finance.yahoo.com/?version=2`(订阅 `QQQ`,消息是 base64 的 protobuf,页面里自己解码) |

币安数据流 10 秒没数据会自动改成每 3 秒轮询历史接口,圆点变黄。你的网络必须能访问上面这些地址。

## 已知限制

- 周线和月线的历史很短(永续合约的 K 线从 2026 年 4 月开始,周线约 30 根、月线个位数),不足 20 根时布林线不会出现,月线基本看不到布林线。
- Yahoo 推送只在有成交或报价时才发消息,休市时可能很久没有新价格,数字会变淡。
- 夜盘(美东 20:00 到次日 04:00)Yahoo 是否推送夜盘价,开发时没有验证过。
- 没有价格提醒、没有开机自启,这是有意不做的。

## 开发和更新

```
web/qqqusdt_float.html     网页版,也是程序版的界面(唯一的界面源码)
```

本地运行程序版(在本目录下):

```
pip install -r app/requirements.txt
python app/main.py                         # 正常运行
python app/main.py --selftest out.json     # 自检:开 3 个窗口、换品种、关一个再补一个,把页面读到的数字写进 out.json
```

发布新版本(标签带项目前缀,只会构建这个项目):

```
git tag qqqusdt-v0.1.4
git push origin qqqusdt-v0.1.4      # GitHub Actions 构建并把文件挂到这个标签的 Release 上
```

只改网页版的话,改 `web/qqqusdt_float.html` 后提交即可;程序版要重新打 tag 才会带上新页面。
